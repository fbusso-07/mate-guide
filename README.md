# Mate Guide

Una guía estática en inglés para aprender a tomar mate, la bebida tradicional
de Argentina, Uruguay, Paraguay y el sur de Brasil. El sitio explica qué es
el mate y la yerba mate, qué elementos se necesitan, cómo prepararlo paso a
paso, la temperatura del agua recomendada, la etiqueta al compartirlo en
grupo, y termina con un checklist rápido para principiantes.

## Ver el sitio completo

El sitio está publicado con GitHub Pages y se puede visitar acá:

**https://fbusso-07.github.io/mate-guide/**

## Sobre el proyecto

Es un sitio estático simple, compuesto por:

- `index.html` — contenido y estructura de la guía
- `style.css` — estilos del sitio
- `script.js` — comportamiento interactivo

No requiere build ni dependencias: se puede abrir `index.html` directamente
en el navegador para verlo en local.
